# 32 起動先とデータの扱い

- 実装: `../pages/32_project_runtime.vue`

## 目的

ローカル起動時のアクセス先と、バックエンド再起動でデータが初期化されることを把握する。

## 表示する内容

- 固定見出し「デモプロジェクトの基礎知識 07」
- フロントエンド `http://127.0.0.1:5173`
- バックエンド `http://127.0.0.1:8787`
- ヘルスチェック `http://127.0.0.1:8787/api/health`
- システム仕様書 `http://127.0.0.1:4174`
- 主題「APIのデータはインメモリ。バックエンドを再起動すると初期状態に戻る」

## レイアウト

4つのアクセス先を上から並べ、下部にデータの扱いを大きく表示する。ポート番号は等幅フォントで揃える。

## 振る舞い

アクセス先のあとに、データの扱いを `v-click` で表示する。

## 出典

- [spot-diff-app README](https://github.com/petaxa/spot-diff-app/blob/main/README.md)

## 維持すること

データが永続化されるように誤解させない。再現確認では必要に応じて再起動で初期状態へ戻せることを伝える。
