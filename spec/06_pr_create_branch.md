# 06 PRの作り方 1: 作業ブランチ

- 実装: `../pages/06_pr_create_branch.vue`

## 目的

修正を始める前に、作業用のブランチを作ることを理解する。

## 表示する内容

- 固定見出し「PRの作り方 01」
- タイトル「作業ブランチを作る」
- コマンド `git switch -c fix/<短い名前>`
- 補足「このブランチで変更をコミットする」

## レイアウト

タイトルの下に大きなコマンドブロックを置き、補足は下側へ短く添える。

## 振る舞い

なし。

## 維持すること

ブランチ名は例であり、参加者が作業内容を識別できる短い名前へ置き換えることを示す。
