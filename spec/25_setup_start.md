# 25 開発環境のセットアップ 4: 起動

- 実装: `../pages/25_setup_start.vue`

## 目的

フロントエンドとバックエンドを同時に起動し、ハンズオンを始められる状態にする。

## 表示する内容

- 固定見出し「開発環境のセットアップ 04」
- タイトル「アプリを起動する」
- コマンド `vp run dev:all`
- 起動確認先
  - フロントエンド `http://127.0.0.1:5173`
  - バックエンド `http://127.0.0.1:8787`

## レイアウト

コマンドを中央のコードブロックに置き、二つのURLをその下へ横並びで表示する。

## 振る舞い

起動確認先を `v-click` で表示する。

## 出典

- [spot-diff-app README](https://github.com/petaxa/spot-diff-app/blob/main/README.md)

## 維持すること

このターミナルはバックエンドログの確認にも使うため、起動後に閉じないことを口頭で補足できる構成にする。
