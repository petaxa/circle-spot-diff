# 07 PRの作り方 2: Push

- 実装: `../pages/07_pr_push.vue`

## 目的

変更をコミットし、作業ブランチをGitHubへPushする手順を理解する。

## 表示する内容

- 固定見出し「PRの作り方 02」
- タイトル「変更をコミットしてPushする」
- コマンド

```bash
git add <変更したファイル>
git commit -m "fix: <直した内容>"
git push -u origin fix/<短い名前>
```

- 補足「最初のPushでは `-u` で追跡先を設定する」

## レイアウト

3行のコマンドを一つのコードブロックに置き、補足を下側へ短く添える。

## 振る舞い

なし。

## 維持すること

06ページと同じブランチ名の例を使う。`git add .`を既定の例にせず、変更したファイルを指定する。
