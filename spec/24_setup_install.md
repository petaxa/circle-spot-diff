# 24 開発環境のセットアップ 3: 依存関係のインストール

- 実装: `../pages/24_setup_install.vue`

## 目的

利用するパッケージマネージャーを一つ選び、依存関係をインストールする。

## 表示する内容

- 固定見出し「開発環境のセットアップ 03」
- タイトル「依存関係をインストールする」
- 切り替えタブ「npm」「pnpm」「Vite+」
- 各タブのコマンド
  - npm: `npm i`
  - pnpm: `pnpm i`
  - Vite+: `vp i`
- 初期選択は「Vite+」
- 補足「どれか一つだけ実行する」

## レイアウト

ライブラリドキュメントのコード例にあるタブ切り替えの表現を使う。選択中のタブだけをアクセント色で示し、その下のコードブロックを切り替える。

## 振る舞い

タブのクリックで表示するコマンドを切り替える。スライドのクリック進行とは分離し、選択状態をページ内で保持する。

## 維持すること

3コマンドを同時に実行する手順に見せない。キーボード操作と選択状態が分かるアクセシビリティを確保する。
