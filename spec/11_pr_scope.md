# 11 PRの修正範囲

- 実装: `../pages/11_pr_scope.vue`

## 目的

Descriptionで共有する修正範囲を、一つのバグに絞る理由を理解する。

## 表示する内容

- 固定見出し「PRの作り方」
- 主題「1つのPRでは、1つのバグ修正だけを扱う」
- 補足「別の問題は同じPRに混ぜず、記録して別のPRで扱う」

## レイアウト

前ページと同じトンマナで、主題を中央に大きく置き、補足をその下に添える。

## 振る舞い

なし。

## 維持すること

具体的なバグや修正コードは載せず、レビュアーが確認できる小さな範囲を保つ考え方に集中する。
