# 27 タスクに対する操作

- 実装: `../pages/27_project_task_features.vue`

## 目的

Tasklyでタスクに対して行える基本操作を把握する。

## 表示する内容

- 固定見出し「デモプロジェクトの基礎知識 02」
- 項目「追加」: 開始日と期限を含むタスクを登録する
- 項目「更新」: タスク名と完了状態を変更する
- 項目「削除」: 不要なタスクを削除する
- 項目「詳細」: 一件のタスク情報を表示する
- 画像 `../public/images/27-taskly-task-list.jpg`

## レイアウト

Tasklyのタスクリスト画面を中央から右へ大きく置き、追加フォーム、完了切り替え、編集、削除の操作箇所が見える範囲を使う。4項目は左側へ短く並べる。

## 振る舞い

4項目を `v-click` で一つずつ表示する。
